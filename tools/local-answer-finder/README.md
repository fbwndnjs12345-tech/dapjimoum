# 답지모음 Windows 로컬 탐색기

Windows 10/11용 데스크톱 프로그램입니다. 교재명을 기준으로 Google·Bing 공개 검색과 설정된 출판사 자료실을 탐색해 답지 링크 **후보**를 모읍니다. 후보는 자동으로 사이트에 공개되지 않으며, Supabase 관리자 검수 대기 목록으로 등록한 뒤 관리자가 확인해야 합니다.

## 1. 설치 및 실행

1. GitHub 저장소의 **Actions** 탭을 엽니다.
2. 가장 최근의 **Build local answer finder** 실행을 선택합니다.
3. 모든 단계가 초록색 체크이고 결과가 **Success**인지 확인합니다.
4. 아래 **Artifacts**에서 `답지모음-로컬-탐색기-Windows` ZIP을 받습니다.
5. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 선택합니다.
6. 압축을 푼 폴더 안의 `DapjiMoumFinder.exe`를 실행합니다.

Python을 따로 설치할 필요가 없습니다. Windows SmartScreen 경고가 나타나면 출처와 파일을 확인한 뒤 실행 여부를 직접 판단하세요.

## 2. 처음 사용할 때

프로그램은 **시작하기 → 검색 및 결과 → 고급 설정** 순서로 구성되어 있습니다.

### 방법 A: 교재 CSV로 시작하기

1. **시작하기** 탭에서 **CSV 파일 선택**을 누릅니다.
2. 교재 CSV 파일을 선택합니다.
3. 화면에 **준비 완료 · 교재 N권**이라고 표시되는지 확인합니다.
4. **검색 및 결과** 탭을 열고 **검색 시작**을 누릅니다.

CSV의 필수 열은 `title` 또는 `교재명`입니다. Supabase에 후보를 등록하려면 각 행에 교재 `id` 열도 있어야 합니다. UTF-8, UTF-8 BOM, CP949 인코딩을 지원합니다.

### 방법 B: Supabase에서 교재 가져오기

1. **시작하기** 탭에서 **연결 설정 펼치기**를 누릅니다.
2. Supabase 프로젝트 URL, anon/publishable key, 관리자 이메일, 비밀번호를 입력합니다.
3. **로그인하고 교재 가져오기**를 누릅니다.
4. 교재 수와 **준비 완료** 상태를 확인합니다.

프로젝트 URL은 Supabase 프로젝트의 Project URL입니다. 키는 공개용 anon 또는 publishable key를 사용합니다. 비밀번호는 설정 파일에 저장하지 않습니다. 관리자 계정에 교재 조회 권한이 있어야 합니다.

Supabase 연결 없이도 CSV만으로 검색할 수 있습니다. 다만 사이트 등록에는 관리자 로그인이 필요합니다.

## 3. 검색 및 후보 확인

1. **검색 및 결과** 탭을 엽니다.
2. **검색 시작**을 누릅니다.
3. 진행 상태와 상세 로그를 확인합니다. 검색 중에는 프로그램을 종료하지 마세요.
4. Google이 사용자 인증을 요구하면 표시된 브라우저에서 직접 인증합니다. 인증이 되지 않아도 가능한 다른 검색 결과는 계속 처리합니다.
5. 검색이 끝나면 후보 목록을 확인합니다. 주소를 더블클릭하면 해당 페이지가 열립니다.
6. 필요하면 **결과 CSV 열기**로 전체 결과를 확인합니다.

검색 결과는 정답 링크가 확정된 목록이 아니라 검수할 후보입니다. 교재명, 과목, 학년, 학기와 페이지 내용을 직접 확인하세요.

## 4. 사이트에 후보 등록

1. **시작하기** 탭의 Supabase 연결 설정에서 관리자 로그인을 완료합니다.
2. 검색을 실행해 후보 CSV를 생성합니다.
3. **검색 및 결과** 탭에서 **Supabase 검수 대기 목록에 등록**을 누릅니다.
4. 등록 확인창에서 진행을 승인합니다.
5. 사이트 관리자 페이지의 답지 링크 검수 화면에서 후보를 확인하고 승인 또는 거절합니다.

이 작업은 후보를 검수 대기 상태로 전달할 뿐, 답지 링크를 자동 공개하지 않습니다. 등록 전 CSV에 교재 ID가 있는지 확인합니다.

## 5. 오류가 발생했을 때

- **교재 목록을 선택하지 않았습니다**: CSV를 선택하거나 Supabase에서 교재를 가져옵니다.
- **CSV에 교재명 열이 필요합니다**: 첫 행의 열 이름을 `title` 또는 `교재명`으로 바꿉니다.
- **Supabase 로그인 실패**: Project URL, anon/publishable key, 이메일, 비밀번호를 다시 확인합니다.
- **교재가 0권 조회됨**: 관리자 계정의 `books` 읽기 권한과 교재 등록 여부를 확인합니다.
- **Google 검색 건너뜀**: Google이 자동화 요청을 차단했을 수 있습니다. 브라우저 표시 옵션을 켜고 직접 인증하거나 Bing 결과를 확인합니다.
- **검색이 오래 걸림**: 검색 중지 버튼을 누르면 현재까지의 후보를 CSV로 저장합니다.
- **설정 오류**: 일반 사용자는 고급 설정을 변경하지 말고 기본 설정을 사용합니다.

오류가 반복되면 **검색 및 결과 → 상세 진행 로그**의 마지막 오류 문구와 `%LOCALAPPDATA%\DapjiMoum\LocalAnswerFinder\answer-link-candidates.csv` 파일을 확인하세요.

## 6. 저장 위치

사용자 데이터는 설치 폴더가 아닌 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\DapjiMoum\LocalAnswerFinder\
├── sources.json                 검색 출처 및 옵션
├── books.csv                    Supabase에서 가져온 교재 목록
└── answer-link-candidates.csv   검색 후보 결과
```

따라서 프로그램을 업데이트하거나 다른 폴더로 옮겨도 사용자 데이터가 설치 파일과 분리됩니다.

## 7. 고급 설정

**고급 설정** 탭의 JSON은 출판사 자료실, 검색엔진, 검색어 수 등을 조정하는 용도입니다. 일반 사용자는 수정할 필요가 없습니다. 잘못 수정했다면 **기본 설정으로 복원**을 누르세요.

## 제한 사항

- Google·Bing의 공개 검색 결과는 네트워크, 지역, 검색엔진 정책에 따라 달라질 수 있습니다.
- CAPTCHA, 로그인, 유료 구독, robots.txt 등 접근 제한을 우회하지 않습니다.
- 모든 검색 후보가 실제 정답 파일인 것은 아닙니다. 사이트 등록 후 관리자가 반드시 검수해야 합니다.
