# 답지모음 로컬 링크 탐색기 (Windows)

v2.4.0은 Windows DPI 인식과 화면 크기 기반 창 배치를 유지하면서 UI 테마를 Windows 버전별로 달라지지 않는 고정 `clam` 테마로 통일했습니다. 한글 글꼴, 버튼·입력창·탭·표의 배경과 상태 색상을 일관되게 재설계했습니다. 브라우저 표시를 기본 활성화해 CAPTCHA가 나타나면 사용자가 직접 체크할 수 있으며, 인증이 사라지면 탐색을 자동 재개합니다. CAPTCHA를 자동 해결하거나 우회하지 않습니다. 설치된 Edge/Chrome의 실제 HTTP 페이지 이동과 CAPTCHA 감지 테스트를 실행 파일 자체 테스트에서 확인합니다. 데이터·검색 설정·탐색 결과를 분리하고, 교재/후보 요약, 진행률, 후보 필터, 실행 로그를 제공합니다. 후보 목록은 최대 1,000행만 화면에 렌더링하며 전체 데이터는 CSV에 보존합니다. 실행 로그도 최근 5,000행으로 제한해 장시간 작업 시 UI 메모리 증가를 억제합니다. 설정·교재 CSV·결과는 `%LOCALAPPDATA%\\DapjiMoumFinder`에 저장해 설치 폴더 쓰기 권한 문제를 피하고, 이전 실행 폴더의 설정·결과 파일은 최초 실행 시 복사합니다.

Windows용 데스크톱 프로그램입니다. Kakao 공식 REST API의 웹문서·블로그·카페 검색과 설정된 출판사 공식 자료실의 공개 페이지·사이트맵을 탐색해 답지 링크 후보를 수집합니다. 웹 검색을 사용하려면 Kakao REST API 키가 필요하며, 키 없이도 공식 자료실 탐색은 가능합니다.

## 다운로드 및 실행

1. GitHub 저장소의 Actions 탭에서 최신 Build local answer finder 실행을 엽니다.
2. 실행 결과가 성공이면 Artifacts에서 답지모음-로컬-탐색기-Windows를 다운로드합니다.
3. ZIP을 압축 해제합니다.
4. 폴더 안의 DapjiMoumFinder.exe를 실행합니다.

이 패키지는 Python과 필요한 라이브러리를 포함하므로 별도 Python 설치나 BAT 실행이 필요하지 않습니다. 브라우저는 Windows에 설치된 Microsoft Edge를 우선 사용하고, Edge가 없으면 Google Chrome을 사용합니다. 브라우저를 패키지에 중복 포함하지 않아 다운로드 크기를 줄였습니다.

**스마트 앱 컨트롤 관련 주의:** 서명되지 않은 실행 파일은 스마트 앱 컨트롤이 차단할 수 있습니다. EXE 패키징만으로 차단 해제가 보장되지는 않습니다. 현재 빌드에는 코드 서명 인증서가 없습니다. 스마트 앱 컨트롤을 끄거나 우회하지 마세요.

## 사용 순서

1. 선택적으로 Supabase URL, anon/publishable key, 관리자 이메일과 비밀번호를 입력하고 로그인 후 교재 CSV를 저장합니다. 비밀번호는 파일에 저장하지 않습니다.
2. Supabase에서 가져오거나 id,title,publisher,subject,grade,semester,series 열이 있는 CSV를 선택합니다.
3. 검색 설정에서 `web_search.enabled`를 true로 두고 `engines`에 `kakao_web`, `kakao_blog`, `kakao_cafe`를 지정합니다. Kakao REST API 키는 데이터 및 계정 화면에 입력합니다. API 키는 설정 파일에 저장하지 않습니다.
4. 공식 자료실도 탐색하려면 `sources` 배열에 출판사명과 자료실 주소를 추가합니다. 출처별 페이지 한도 기본값은 80페이지이며, 사용자가 1~500페이지 범위에서 조정할 수 있습니다. 공식 검색 API만 사용할 경우 `sources`를 빈 배열로 둘 수 있습니다.
5. 탐색 시작을 누르면 `%LOCALAPPDATA%\\DapjiMoumFinder\\answer-link-candidates.csv`에 결과가 저장됩니다.
6. 탐색이 끝나도 Supabase 업로드는 기본적으로 자동 실행되지 않습니다. 후보를 사이트에 등록하려면 로그인한 뒤 '후보 업로드'를 누르고 확인해야 합니다. 등록된 후보는 관리자 검수 대기 상태이며 자동 승인되지 않습니다.

후보 등록을 위해 저장소 루트에서 최초 1회 다음 Edge Function을 올바른 Supabase 프로젝트에 배포해야 합니다:

```bash
supabase functions deploy answer-link-import-candidates
```

## 검색 범위 및 제한

- Kakao 공식 REST API의 웹문서·블로그·카페 검색을 사용합니다. 예시 설정은 교재별 최대 3개 검색어와 API 종류별 최대 5개 결과입니다. 교재별 후보는 기본 최대 5개로 제한합니다. 같은 실행 안에서 중복 검색어의 엔진 응답과 이미 확인한 페이지 본문을 재사용하고, likely 후보 3개를 확보하면 해당 교재의 추가 검색어 요청을 조기 종료합니다. 이 최적화는 검색 요청 수와 동일 페이지 재방문을 줄이며, 대상 사이트의 요청 간격 설정은 유지합니다.
- 티스토리와 네이버 블로그 등 공개 블로그 플랫폼을 겨냥한 검색어도 포함합니다. 검색엔진 색인 범위에 따라 누락될 수 있습니다.
- 후보는 교재명 토큰, 시리즈, 과목, 학년·학기, 정답 관련 문구를 종합 평가하며 다른 학기·학년이 명확하면 제외합니다. 점수는 자동 확정이 아니라 검수 우선순위입니다.
- Kakao API가 인증·권한·쿼터 오류(401/403/429)를 반환하면 해당 검색 경로를 이번 실행에서 중단합니다. API 오류를 우회하거나 HTML 검색 결과 페이지로 대체하지 않습니다.
- 검색 결과에서 발견한 각 사이트의 `robots.txt`를 확인합니다. robots.txt를 읽을 수 없거나 접근이 금지된 URL은 건너뜁니다.
- 로그인, 유료 페이지, CAPTCHA, 접근 차단을 우회하지 않습니다.
- 검색 결과는 후보일 뿐 실제 정답 자료인지 자동 확정하지 않습니다. 관리자 검수가 필요합니다.
- PDF는 다운로드하지 않고 링크 후보로 기록합니다.
- Kakao 공식 쿼터는 현재 웹문서·블로그·카페 검색 각각 일 30,000회이며, 월간 전체 API 무료 쿼터는 3,000,000회입니다. 쿼터는 변경될 수 있고 앱별 사용량에 합산됩니다.
- 결과 수와 검색 API 가용성을 보장하지 않습니다.
- Google 검색 결과 페이지는 robots.txt에서 `/search`가 Disallow이고, Bing 검색 페이지도 `/search`가 Disallow입니다. Bing Search API는 2025-08-11 종료됐으므로 두 페이지를 직접 수집하지 않습니다. 대신 Kakao 공식 REST API를 사용하며, API 키가 없으면 공식 자료실 탐색만 실행합니다.
- 같은 실행 안에서만 검색 결과와 페이지 본문을 캐시합니다. 실행 간 캐시는 사용하지 않아 오래된 검색 결과가 장기간 재사용되지 않도록 합니다.
- 검색 API 키와 Supabase 세션 토큰은 설정 파일에 저장하지 않습니다. 후보 업로드는 기본 비활성화되어 있으며, 사용자가 별도로 실행해야 합니다. CSV 업로드는 전체 사전 검증 후 100개 단위로 처리하며, 요청 본문 크기도 제한해 메모리 사용량과 서버 요청 크기를 제어합니다.
