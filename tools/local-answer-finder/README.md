# 답지모음 링크 탐색기 (Windows)

Windows 10/11용 데스크톱 앱입니다. 교재별로 Google·Bing 공개 검색과 설정된 출판사 자료실을 탐색해 답지 링크 후보를 CSV로 저장하고, 로그인한 관리자 계정이 있으면 Supabase 검수 대기 목록으로 자동 전송합니다.

> 검색 결과는 답지 확정본이 아닙니다. PDF 본문은 현재 자동 판독하지 않으며, 모든 후보는 관리자 검수 후 공개됩니다.

## 1. 다운로드 및 설치

### 1-1. 최신 설치 패키지 받기

1. [최신 Windows 빌드 결과 열기](https://github.com/fbwndnjs12345-tech/dapjimoum/actions/runs/43145400513)
2. 페이지의 **Artifacts** 영역으로 이동합니다.
3. **답지모음-로컬-탐색기-Windows**를 클릭해 ZIP 파일을 다운로드합니다.
4. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **압축 풀기**를 선택합니다.
5. 압축을 푼 폴더를 PC의 문서 또는 바탕화면 아래에 보관합니다.
6. 폴더 안의 `DapjiMoumFinder.exe`를 더블클릭해 실행합니다.

현재 빌드 패키지는 약 395MB입니다. Actions artifact는 생성일로부터 30일간 보관됩니다. 이 빌드의 표시 만료일은 2026-12-12입니다. 만료되면 같은 Actions 페이지에서 새로 성공한 빌드를 다운로드해야 합니다.

### 1-2. 별도 설치가 필요한가?

- Python 설치: **필요 없음**
- pip 또는 라이브러리 설치: **필요 없음**
- Playwright / Chromium 별도 설치: **필요 없음** (패키지에 포함)
- BAT 파일 실행: **필요 없음**
- 인터넷 연결: **필요함** (검색 및 Supabase 연결에 사용)

압축을 푼 폴더 안의 파일과 `ms-playwright` 폴더를 삭제하거나 EXE만 따로 옮기지 마세요.

### 1-3. Windows 보안 경고

현재 EXE는 코드 서명 인증서로 서명되지 않았습니다. Windows Smart App Control 또는 조직의 보안 정책이 실행을 차단할 수 있습니다. GitHub Actions에서 빌드와 자체 테스트가 성공했다는 사실이 Microsoft의 신뢰 서명이나 무차단 실행을 의미하지는 않습니다.

- Windows 보안 기능을 끄거나 우회하지 마세요.
- 학교·회사 노트북에서 차단되면 관리자 또는 IT 담당자에게 승인된 실행 파일인지 확인을 요청하세요.
- 실행이 차단된 경우 임의의 미러 사이트에서 EXE를 받지 말고 공식 저장소의 Actions artifact만 사용하세요.

## 2. 첫 실행 및 Supabase 연결

프로그램 상단의 **① 교재 및 연결** 탭에서 설정합니다.

### 2-1. 입력값

| 입력란 | 입력할 값 |
|---|---|
| 프로젝트 URL | `https://puafssyzhrjjpsxzmkxr.supabase.co` |
| Anon / Publishable Key | Supabase 프로젝트의 공개 클라이언트 키 |
| 관리자 이메일 | Supabase Authentication에 등록된 관리자 이메일 |
| 관리자 비밀번호 | 해당 계정의 비밀번호 |

관리자 이메일은 단순히 Authentication에 등록된 것만으로 충분하지 않습니다. 해당 사용자는 `public.admin_users`에도 등록되어 있어야 합니다. 비밀번호는 파일에 기록하지 않습니다.

공개 키는 Supabase 대시보드의 **Project Settings → API**에서 확인합니다. `service_role` 또는 Secret Key는 절대로 로컬 프로그램에 입력하거나 공유하지 마세요.

### 2-2. 로그인하고 교재 가져오기

1. URL과 공개 키, 관리자 이메일·비밀번호를 입력합니다.
2. **로그인 및 교재 가져오기**를 누릅니다.
3. 성공 메시지가 표시되고 교재 CSV가 저장될 때까지 기다립니다.
4. 가져오기에 실패하면 인터넷 연결, URL·키, 계정 비밀번호, 관리자 등록 여부를 확인합니다.

서버의 교재 테이블은 `public.books`입니다. 프로그램은 교재 ID와 이름, 출판사, 과목, 학년, 학기 등의 정보를 읽습니다. 답지 후보는 이 교재 ID와 연결되므로, 일반적인 제목만 있는 CSV보다 서버에서 내려받은 교재 CSV를 권장합니다.

### 2-3. CSV로만 실행하는 경우

Supabase 연결 없이도 CSV로 검색할 수 있습니다. CSV에는 최소한 `title` 또는 `교재명` 열이 있어야 합니다.

다만 Supabase에 후보를 등록하려면 각 행에 실제 교재의 `id` 또는 `book_id`가 있어야 합니다. ID가 빠진 CSV는 업로드 단계에서 거부됩니다.

## 3. 출처 설정

**② 출처 설정** 탭에는 JSON 형식의 설정이 표시됩니다.

- `web_search.enabled`: 공개 검색 사용 여부
- `web_search.engines`: Google 및 Bing 선택
- `sources`: 출판사 공식 자료실 주소 목록
- `request_delay_seconds`: 요청 사이 대기 시간
- `max_sitemap_urls_per_source`: 자료실 사이트맵 탐색 상한

기본 공개 검색을 사용하려면 Google·Bing이 활성화되어 있어야 합니다. 공식 자료실 주소를 추가하지 않아도 공개 웹 검색은 실행할 수 있습니다. JSON을 수정했다면 **설정 저장 및 검사**를 눌러 유효성 검사를 통과시킵니다.

설정 JSON을 잘 모르면 처음에는 기본값을 그대로 사용하세요.

## 4. 검색 실행

**③ 탐색 및 결과** 탭에서 실행합니다.

1. 교재 CSV가 올바른지 확인합니다.
2. 출처별 최대 페이지 수를 지정합니다. 처음에는 기본값을 권장합니다.
3. Google 인증 화면을 직접 처리하려면 **브라우저 창 표시**를 켭니다.
4. **검색 종료 후 Supabase 자동 업로드**를 켜 둡니다.
5. **탐색 시작**을 누릅니다.

프로그램은 교재명, 출판사, 시리즈, 과목, 학년·학기와 답지 관련 문구를 결합해 검색합니다. 티스토리·네이버 블로그·블로그스팟 등 공개 블로그를 겨냥한 검색어도 포함합니다.

- 진행 상황은 로그와 후보 미리보기에서 확인합니다.
- 후보 URL을 더블클릭하면 브라우저에서 열 수 있습니다.
- 중지하려면 **중지 및 결과 저장**을 누릅니다.
- **결과 CSV 열기**로 저장된 후보 파일을 확인할 수 있습니다.

## 5. Supabase 자동 업로드

자동 업로드 옵션이 켜져 있고 관리자 로그인이 유지된 상태라면 검색 종료 후 후보 CSV를 자동으로 전송합니다.

1. CSV에서 교재 ID와 후보 URL을 확인합니다.
2. 100개 단위로 `answer-link-import-candidates` Edge Function에 전송합니다.
3. 로그인 토큰이 만료되면 Refresh Token으로 갱신을 시도합니다.
4. 서버는 JWT와 관리자 권한을 확인합니다.
5. 중복 후보를 제외하고 신규 후보를 `public.answer_link_candidates`에 저장합니다.
6. 프로그램은 신규·중복 건수를 로그와 완료 알림에 표시합니다.

업로드된 후보는 검수 대기 상태입니다. 관리자가 확인하고 승인해야 공개 답지 링크 테이블인 `answer_links`에 반영됩니다. 이 프로그램은 자동 승인하거나 사이트에 즉시 공개하지 않습니다.

자동 업로드를 끄면 CSV만 저장됩니다. 로그인하지 않은 경우에도 검색과 CSV 저장은 가능하지만 서버 업로드는 실행되지 않습니다.

### Supabase 업로드가 실패하면

- 로그인 오류: 관리자 계정과 공개 키를 확인하고 다시 로그인합니다.
- 권한 오류: 해당 사용자가 `admin_users`에 등록되어 있는지 확인합니다.
- 교재 ID 오류: 서버에서 다시 교재 CSV를 가져옵니다.
- Edge Function 오류: Supabase 프로젝트에서 `answer-link-import-candidates`가 배포되어 있고 ACTIVE인지 확인합니다.
- 일부 배치만 실패: 저장된 CSV를 보관하고 원인을 해결한 뒤 다시 업로드합니다. 서버 중복 검사가 같은 후보의 재등록을 방지합니다.

프로그램에서 사용하는 Edge Function은 `answer-link-import-candidates`입니다. 배포·수정이 필요한 경우 저장소 루트에서 프로젝트 연결 상태를 확인한 뒤 다음 명령을 실행합니다.

```bash
supabase functions deploy answer-link-import-candidates
```

## 6. 결과 파일 위치

프로그램을 실행한 폴더에 다음 파일이 생성됩니다.

- `books.csv`: Supabase에서 가져온 교재 목록
- `answer-link-candidates.csv`: 검색 후보 결과
- `sources.json`: 출처 설정 (기본 파일이 제공된 경우)

폴더를 다른 위치로 이동할 때는 EXE와 함께 제공된 폴더 전체를 이동하세요. 후보 CSV는 별도로 복사해 백업할 수 있습니다.

## 7. 검색 범위와 한계

- Google·Bing의 공개 검색 결과와 설정된 출판사 공개 자료실을 사용합니다. 별도 검색 API 키는 필요하지 않습니다.
- 검색엔진의 색인 범위, CAPTCHA, 일시 차단, 네트워크 환경에 따라 결과가 달라질 수 있습니다.
- CAPTCHA·로그인·유료 페이지·접근 차단을 우회하지 않습니다. Google 인증이 필요하면 사용자가 직접 처리해야 하며, Google이 막혀도 가능한 경우 Bing 검색을 계속합니다.
- robots.txt에서 접근을 금지한 페이지는 탐색하지 않습니다.
- PDF 파일을 다운로드해 본문까지 확인하는 기능은 아직 없습니다. PDF 후보는 자동 확정하지 않고 관리자 확인 대상으로 둡니다.
- 검색 점수는 검수 우선순위일 뿐 정답 여부를 보증하지 않습니다.
- 안전하지 않은 URL, localhost, 사설 IP, 비웹 스킴 및 위험한 리디렉션은 차단합니다.
- 검색 후보의 누락이나 검색엔진의 응답 지연은 발생할 수 있습니다.

## 8. 문제 해결

| 증상 | 조치 |
|---|---|
| EXE가 실행되지 않음 | 압축을 완전히 풀었는지, 폴더 안의 파일을 삭제하지 않았는지 확인 |
| Smart App Control 차단 | 보안 기능을 끄지 말고 학교·회사 관리자에게 확인 |
| 교재가 안 보임 | Supabase 로그인 및 교재 가져오기 결과 확인 |
| 검색 결과가 적음 | Google·Bing 접근 상태, 검색어, 출처 설정, 네트워크 확인 |
| Google 인증 화면이 나타남 | 브라우저에서 직접 인증하거나 Bing 결과 확인 |
| 자동 업로드가 건너뛰어짐 | 관리자 로그인 상태와 자동 업로드 체크 여부 확인 |
| 후보가 공개 사이트에 안 나타남 | 정상 동작일 수 있음. 관리자 검수·승인이 먼저 필요 |
