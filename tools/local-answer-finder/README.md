# 답지모음 로컬 탐색기 (Windows)

## 현재 버전

- 데스크톱 UI: 글자 크기 9~16 조절, 사용 방법 탭, 설정/결과 폴더 바로 열기
- API 없는 기본 검색: 출판사 공식 자료실 5곳(비상교육·지학사·천재교육·NE능률·좋은책신사고)
- 교재별 출판사 자체 검색 폼(GET)이 감지되면 교재명·과목·학년·학기·판본을 조합해 추가 검색
- 공식 자료실의 사이트맵, 자료 목록, 페이지 링크, 다운로드 링크 및 별도 공개 파일 호스트를 확인
- ISBN·교재명·시리즈·과목·학년·학기·판본·정답 관련 문구를 함께 비교
- 교재별 검색 결과 없음/후보 발견 현황을 실행 로그에 출력
- 후보 CSV는 체크포인트 및 최종 저장으로 보존

## 중요한 사실: 검색 결과 100% 보장은 불가능

API 키가 없고, 모든 검색엔진·출판사 사이트에 공개 접근할 수 있는 것은 아닙니다. 현재 기본 모드는 설정된 출판사 공식 공개 자료실과 공개된 출판사 자체 검색창만 자동 탐색합니다.

- 출판사 사이트가 로그인, 구매 인증, POST 전용 검색, CAPTCHA 또는 접근 차단을 요구하면 자동으로 우회하지 않습니다.
- Google·Bing·Naver 검색 결과 페이지를 비공식 방식으로 무단 수집하지 않습니다.
- 공식 자료실이 바뀌거나 교재가 자료실에 등록되지 않았으면 검색 결과가 없을 수 있습니다.
- ‘likely’는 검수 우선순위이지 정답 확정 표시가 아닙니다. ISBN·학년·학기·개정판과 실제 문항을 확인하세요.
- 따라서 ‘무조건 결과가 나온다’고 약속하지 않습니다. 대신 모든 교재의 검색 여부와 결과 없음 상태를 로그에 남겨 누락을 숨기지 않습니다.

## 다운로드 및 실행

1. GitHub 저장소의 Actions 탭에서 최신 **Build local answer finder** 실행을 엽니다.
2. 실행 결과가 성공이면 Artifacts에서 `답지모음-로컬-탐색기-Windows`를 다운로드합니다.
3. ZIP 파일을 압축 해제합니다.
4. 폴더 안의 `DapjiMoumFinder.exe`를 실행합니다.

이 패키지는 Python과 필요한 라이브러리를 포함하므로 별도 Python 설치나 BAT 실행이 필요하지 않습니다. 브라우저는 Windows에 설치된 Microsoft Edge를 우선 사용하고, Edge가 없으면 Google Chrome을 사용합니다.

**Windows 보안:** 현재 EXE에는 코드 서명 인증서가 없습니다. Smart App Control 또는 조직 정책이 실행을 차단할 수 있습니다. 보안 기능을 끄거나 우회하지 마세요.

## 처음 실행하는 순서

### 1. 교재 CSV 선택

- `데이터 및 계정` 탭에서 **CSV 파일 선택**을 누릅니다.
- 필수 열은 `title` 또는 `교재명`입니다.
- 권장 열: `publisher`, `subject`, `grade`, `semester`, `series`, `edition`, `curriculum_revision`, `isbn13`.
- 한글 Excel CSV(CP949)와 UTF-8 BOM CSV를 읽을 수 있습니다.
- Supabase 로그인은 로컬 CSV 검색에 필요하지 않습니다.

### 2. 검색 출처 확인

- `검색 설정` 탭의 `sources`에 기본 출판사 자료실 주소가 들어 있습니다.
- 기본 출처는 비상교육, 지학사, 천재교육, NE능률, 좋은책신사고입니다.
- 다른 출판사는 공식 자료실의 공개 URL을 추가해야 합니다.
- `max_sitemap_urls_per_source`는 출처별 탐색 페이지 한도입니다.
- 설정을 바꾸면 **설정 저장 및 유효성 검사**를 누릅니다.

### 3. 검색 실행

- `탐색 결과` 탭으로 이동합니다.
- 브라우저 표시를 켜고 **탐색 시작**을 누릅니다. 브라우저 표시를 끄면 사람이 직접 CAPTCHA를 처리할 수 없습니다.
- 사이트에서 사람 확인이 나오면 브라우저에서 직접 처리합니다. 정해진 시간 안에 해결되지 않으면 해당 페이지를 건너뜁니다.
- **중지 및 저장**을 누르면 현재까지의 결과를 저장합니다.

### 4. 결과 검수

- 후보 목록을 교재명 또는 주소 일부로 필터링할 수 있습니다.
- 항목을 두 번 클릭하면 후보 페이지를 엽니다.
- `likely`도 자동 확정이 아닙니다. 표지·학년·학기·교육과정·ISBN을 대조하세요.
- `uncertain`은 정보가 부족하므로 수동 확인이 필요합니다.
- 실행 로그의 `[검색 결과 없음]`은 해당 교재에서 후보가 발견되지 않았다는 뜻입니다. 출처 누락, 로그인 요구, 검색 폼 구조, robots 정책, 교재 메타데이터를 확인하세요.

## 결과와 설정 파일

모든 파일은 다음 위치에 저장됩니다.

`%LOCALAPPDATA%\\DapjiMoumFinder`

- `sources.json`: 검색 출처 및 탐색 설정
- `books.csv`: Supabase에서 내려받은 교재 목록
- `answer-link-candidates.csv`: 검색 후보 전체 결과

앱의 `사용 방법` 탭에서 결과 폴더와 설정 파일을 바로 열 수 있습니다.

## 검색 전략

- API 키 없는 모드가 기본값입니다.
- 출판사 자료실의 공개 페이지와 사이트맵을 탐색하고, 공개 GET 검색 폼을 감지하면 교재별 검색을 추가합니다.
- 출판사 자체 검색은 일반 웹 검색 연산자 대신 교재명, 과목, 학년, 학기, 판본 등 일반 텍스트를 사용합니다.
- 공식 자료실에서 연결된 외부 파일 호스트는 공개 HTTP(S) 주소와 해당 호스트의 robots 정책을 확인한 뒤 후보로 기록합니다.
- 후보는 교재별 상위 20개까지 보존합니다.
- 페이지 검증 기본 한도는 교재당 80개입니다. 실제 탐색 페이지 수는 출처 수, 페이지 한도, 사이트 구조에 따라 달라집니다.
- ISBN이 명시적으로 다르면 해당 후보를 제외합니다. ISBN 일치만으로 정답을 확정하지는 않습니다.
- PDF 링크도 파일 내용을 자동으로 읽거나 검증하지 않습니다. 출판사 공식 링크라도 실제 판본을 확인해야 합니다.

## Supabase 연동

Supabase URL, anon/publishable key, 관리자 이메일과 비밀번호는 선택 사항입니다. 로그인하면 교재 목록을 내려받거나 검색 후보를 관리자 검수 대기 목록에 업로드할 수 있습니다. 업로드는 기본적으로 자동 실행되지 않으며, 후보는 자동 승인되지 않습니다.

후보 업로드 기능을 사용하려면 올바른 Supabase 프로젝트에 Edge Function을 배포해야 합니다.

```bash
supabase functions deploy answer-link-import-candidates
```

## 문제 해결

- **교재 CSV를 읽지 못함:** 헤더에 `title` 또는 `교재명`이 있는지 확인합니다.
- **검색 후보가 0개:** `사용 방법` 탭과 실행 로그를 확인하고, 출판사 공식 자료실 주소를 추가합니다. 출판사·학년·학기·ISBN을 CSV에 채우면 잘못된 후보를 줄이는 데 도움이 됩니다.
- **브라우저가 열리지 않음:** Edge 또는 Chrome 설치 상태를 확인하고, 브라우저를 업데이트한 뒤 재실행합니다.
- **CAPTCHA에서 멈춤:** 브라우저 표시를 켜고 직접 인증합니다. 자동 해결이나 우회는 지원하지 않습니다.
- **후보 CSV가 안 보임:** 앱에서 `결과 폴더 열기`를 누릅니다.
- **글자가 작음:** 상단의 `글자 크기`를 9~16에서 조정합니다.
- **자료실 주소가 바뀜:** 공식 사이트의 최신 자료실 주소를 확인해 `검색 설정` 탭의 `sources`에 수정합니다.
